## 🧠 How It Works

EvilEmoji uses **zero-width Unicode characters** — invisible characters that exist in digital text but are not rendered on screen. By mapping binary data to these invisible characters, we can hide entire messages that travel alongside visible content undetected.

### Emoji Mode

```
┌─────────────────────────────────────────────────────────────┐
│  SECRET MESSAGE: "Hi"                                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: Convert to Binary (UTF-8)                          │
│     'H' = 72  → 01001000                                    │
│     'i' = 105 → 01101001                                    │
│     Full binary: "0100100001101001"                         │
│                                                             │
│  Step 2: Map to Zero-Width Characters                       │
│     0 → U+200C (Zero-Width Non-Joiner)  [invisible]         │
│     1 → U+200B (Zero-Width Space)       [invisible]         │
│                                                             │
│  Step 3: Wrap with Cover Emoji                              │
│     Output: 😈 + ZWJ + [payload] + ZWJ                      │
│                                                             │
│  RESULT: Looks like "😈" but secretly contains "Hi"!        │
└─────────────────────────────────────────────────────────────┘
```

### Text Mode

```
┌─────────────────────────────────────────────────────────────┐
│  COVER TEXT:    "Hey, are we still on for dinner tonight?"   │
│  SECRET MESSAGE: "Meet at the dock at 9"                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: Encode secret to zero-width characters (same as    │
│          emoji mode)                                        │
│                                                             │
│  Step 2: Inject payload between first two visible           │
│          characters of the cover text                       │
│     Output: "H" + ZWJ + [payload] + ZWJ + "ey, are we..."  │
│                                                             │
│  RESULT: Looks exactly like                                 │
│     "Hey, are we still on for dinner tonight?"              │
│  but secretly contains "Meet at the dock at 9"!            │
│                                                             │
│  247 invisible characters. Zero visible difference.         │
└─────────────────────────────────────────────────────────────┘
```

### Zero-Width Character Reference

| Character | Unicode | Escape | Purpose |
|-----------|---------|--------|---------|
| Zero-Width Space | `U+200B` | `\u200B` | Binary `1` |
| Zero-Width Non-Joiner | `U+200C` | `\u200C` | Binary `0` |
| Zero-Width Joiner | `U+200D` | `\u200D` | Delimiter/wrapper |

## 🚀 Quick Start

### Prerequisites

- **Node.js** 18.17 or later
- **npm**, **yarn**, or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/EvilEmoji.git
cd EvilEmoji

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📖 Usage

### 🔒 Encoding a Message (Emoji Mode)

1. Navigate to the **ENCODER** tab
2. Select **Emoji** cover mode (default)
3. Type your secret message in the text area
4. Select a cover emoji from the quick-select grid (or use the default 👁️)
5. Click **🔐 ENCRYPT & BIND**
6. Copy the output — it looks like a simple emoji but contains your hidden message!

### 📝 Encoding a Message (Text Mode)

1. Navigate to the **ENCODER** tab
2. Select **Text** cover mode
3. Type your secret message in the "Secret Data" field
4. Type any innocent-looking sentence in the "Cover Text" field
5. Click **🔐 ENCRYPT & BIND**
6. The output looks identical to your cover text — but the secret is hidden inside!

### 🔓 Decoding a Message

1. Navigate to the **DECODER** tab
2. Paste the suspicious emoji or text into the input
3. Click **🔍 DECRYPT** (or enable **Auto-detect on paste**)
4. View the revealed hidden message with confidence level
5. Toggle **Hex View** to inspect the raw binary data

### ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/⌘ + E` | Switch to Encoder tab |
| `Ctrl/⌘ + D` | Switch to Decoder tab |
